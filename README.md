# 🔐 Password Generator - Generador de Contraseñas Seguras

Generador de contraseñas seguras hecho en Python por Mirko David Schiavi.

## 🚀 Características
- Usa `secrets` para seguridad criptográfica real
- Personalizable: mayúsculas, números, símbolos
- Genera múltiples contraseñas a la vez

## 💻 Cómo usar
```bash
python password_generator.py
